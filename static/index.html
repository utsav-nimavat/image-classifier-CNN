Food‑101 Classifier

DeepCNN Model w/ 17.3M params. Predicts out of 101 classes (food categories)

About this project

This model is a convolutional neural network I trained from scratch to recognize 101 different kinds of food from a photo. No pretrained weights were used, every parameter was learned during the training split.

Top-1 accuracy
84.65%
Parameters
17.3M
Training images
75,750

Each photo is shown to the model at three different zoom levels, plus a mirrored copy of each, and the six opinions are averaged. Different crops can get different images wrong, so their mistakes partly cancel out and give us a small ~2.5 point bump in accuracy.

My model was trained on the Food-101 dataset, which contains 101,000 images pertaining to 101 classes. This dataset was published as part of a research paper.

View my code on GitHub! View dataset

Dataset: Bossard, Guillaumin & Van Gool, “Food-101 – Mining Discriminative Components with Random Forests”, ECCV 2014.
